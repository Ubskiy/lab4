## 1. Цель проекта

Создать bash‑скрипт, выполняющий анализ файловой системы преподавателя *labfiles-25* и предоставляющий данные по успеваемости и посещаемости студентов по ряду критериев.

---

## 2. Исходные данные

Скрипт работает со структурой директорий внутри `labfiles-25`:

* **Цирковое_Дело/tests/** — тесты по предмету *Цирковое дело*.
* **Поп-Культуроведение/tests/** — тесты по предмету *Поп‑культуроведение* (опционально; может отсутствовать).
* **students/groups/** — файлы со списками студентов групп.
* **Цирковое_Дело/<group>-attendance** — файлы посещаемости по группам.

Все тестовые файлы имеют формат `TEST-*` и содержат строки вида:

```
<группа>;<логин студента>;<...>;<номер вопроса>;<оценка>
```

---

## 3. Функциональные возможности (реализованные)

Скрипт предоставляет следующие функции через главное меню:

### **3.1 Лучший студент группы по количеству заданной оценки (3/4/5)**

* Анализируются *все тесты* по обоим предметам (если доступны).
* Определяется студент группы, получивший **максимальное количество оценок указанного типа**.
* Выводится список строк из тестов, относящихся к найденному студенту и оценке.

### **3.2 Лучшая посещаемость группы за указанный период занятий**

* Период задаётся параметрами **ОТ** и **ДО**.
* Из файла `<group>-attendance` вычисляются посещения.
* Выводятся все студенты, у которых максимальное число посещений в диапазоне.
* Скрипт корректирует границы, если период выходит за длину строки.

### **3.3 Лучшие студенты по предмету «Цирковое дело»**

* Анализируются *только тесты по Цирковому делу*.
* Рассчитывается средний балл каждого студента.
* Выводятся студенты с **максимальным средним баллом**.

### **3.4 Средняя оценка студента по выбранному предмету**

Пользователь вводит:

* логин студента;
* предмет: 1 — *Цирковое дело*, 2 — *Поп‑Культуроведение*.

Скрипт:

* собирает тесты по выбранному предмету;
* вычисляет средний балл и количество оценок;
* выводит результат.

### **3.5 Список доступных групп**

* На основе файлов в `students/groups`.

### **3.6 Валидация файловой системы**

При запуске выполняется проверка:

* наличия директорий предметов;
* наличия тестов;
* корректности структуры.

При критических ошибках — выход с сообщением.

---

## 4. Требования к тестированию

Тестировщик должен проверить:

* корректность обработки существующих и несуществующих групп;
* ввод некорректной оценки (не 3/4/5);
* ввод некорректных границ периода посещаемости;
* отсутствие тестов по предмету;
* отсутствие данных по студенту;
* корректную работу при пустых и частично пустых каталогах.
